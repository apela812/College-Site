# 🏥 Альметьевский Медицинский Колледж

Современный веб-сайт медицинского колледжа с полноценной админ-панелью для управления пользователями, расписанием, новостями и группами.

**Версия:** v3.0 | **Статус:** ✅ Готово к конкурсу | **Последнее обновление:** 10 марта 2026

---

## ✨ Основные функции

### 👥 Для студентов
- 📅 **Расписание** - просмотр расписания своей группы
- 📰 **Новости** - актуальные новости и объявления
- 👤 **Личный кабинет** - профиль и информация

### 👨‍🏫 Для преподавателей
- 📚 **Доступ к информации** - новости и объявления

### 🔐 Для администраторов
- 👥 **Управление пользователями** - добавление, редактирование, удаление студентов, преподавателей и администраторов
- 👫 **Управление группами** - создание групп, добавление студентов
- 📅 **Управление расписанием** - **⭐ ГЛАВНАЯ ФИШКА**: выбор пар из предопределённого списка (7 пар с фиксированным временем), возможность выбрать несколько пар одновременно, просмотр расписания в таблице
- 📰 **Публикация новостей** - создание новостей на русском и английском языках
- 📊 **Статистика** - аналитика и метрики системы

### 🎬 Интерактивный тур
- **Демонстрационный тур** - полная демонстрация всех функций сайта оргкомитету конкурса
- 🎨 **Красивые анимации** - плавные переходы и эффекты
- 📱 **Адаптивный дизайн** - работает на всех устройствах

## 👨‍💼 Управление пользователями

**URL:** http://localhost:5173/admin

**Стандартный аккаунт:**
- Email: `admin@almetmed.ru`
- Пароль: `admin`

**Создание пользователя:**
1. Админ-панель → Пользователи
2. Нажмите "Добавить пользователя"
3. Выберите роль: Admin, Dean, Teacher или Student
4. Система сгенерирует пароль

---

## 📅 Управление расписанием

**⭐ ГЛАВНАЯ ФИШКА:**

1. **Выбор пар из списка** - вместо ручного ввода времени
2. **7 предопределённых пар:**
   - 1 Пара: 08:00–09:30
   - 2 Пара: 09:40–11:10
   - 3 Пара: 11:30–13:20
   - 4 Пара: 13:30–15:00
   - 5 Пара: 15:10–16:40
   - 6 Пара: 16:50–18:20
   - 7 Пара: 18:30–20:00

3. **Выбрать несколько пар одновременно** - одно занятие создаётся для всех выбранных пар

4. **Просмотр расписания в таблице** - вкладка "Просмотр"

---

## 📰 Управление новостями

1. Админ-панель → Расписание → "Новое занятие"
2. Заполните данные о занятии
3. Выберите день и пару(ы)
4. Нажмите "Сохранить"

Функции:
- 🔍 Поиск по группе, предмету, преподавателю
- 📊 Сортировка (по дням, группам, времени)
- ✏️ Редактирование
- 📋 Дублирование
- 🗑️ Удаление
- ⬇️ Экспорт в JSON

# 🏥 Альметьевский Медицинский Колледж

Современный веб-сайт медицинского колледжа с полноценной админ-панелью для управления пользователями, расписанием, новостями и группами.

**Версия:** v2.2 | **Статус:** ✅ Готово к использованию | **Последнее обновление:** 5 марта 2026

---

## ✨ Основные функции

- 👥 **Управление пользователями** - создание завучей, учителей и студентов
- 📚 **Управление группами** - создание групп с произвольными названиями
- 📅 **Редактирование расписания** - удобный интерфейс с сортировкой, поиском и экспортом
- 📰 **Публикация новостей** - создание новостей на русском и английском языках
- 📊 **Статистика системы** - просмотр распределения пользователей и основных метрик
- 🎯 **Красивая админ-панель** - вкладки, интуитивный интерфейс, отзывчивый дизайн
- 👨‍🎓 **Личный кабинет студента** - просмотр расписания группы, актуальные новости, профиль
- ✅ **Полная управляемость** - все данные создаются только через интерфейс (никаких статических данных)

## 👨‍💼 Управление пользователями

### Вход в админ-панель

**URL:** http://localhost:5000/admin

**Стандартный аккаунт:**
- Email: `admin@almetmed.ru`
- Пароль: `admin` (рекомендуется сменить)

### Создание завуча или учителя

1. **Админ-панель → вкладка "Пользователи"** (видна только админам)
2. **Нажмите "Добавить пользователя"**
3. **Заполните:**
   - Имя и фамилия
   - Email (уникальный)
   - Роль: Dean (Завуч), Teacher (Учитель) или Student (Студент)
4. **Нажмите "Создать"**

Система сгенерирует временный пароль. Пользователь может его сменить при первом входе.

### Роли и права доступа

| Роль | Может создавать | Может редактировать | Может удалять |
|------|-----------------|---------------------|---------------|
| **Admin** | Пользователей, все | Всё | Всё |
| **Dean** | Новости, расписание | Новости, расписание | Новости, расписание |
| **Teacher** | Новости | Свои новости | Свои новости |
| **Student** | - | - | - |

## 📚 Управление группами

### Создание новой группы

1. **Админ-панель → вкладка "Группы"**
2. **Нажмите "Создать группу"**
3. **Заполните:**
   - **Название:** ПВ-201 (произвольно, уникальное)
   - **Специальность:** Сестринское дело (опционально)
   - **Год обучения:** 2 (опционально)
4. **Нажмите "Создать"**

### Примеры структур группировки

**Вариант 1: По программам обучения**
```
ПВ-101 - Программа "Уход за больными" 1 курс
ПВ-102 - Программа "Уход за больными" 1 курс
ПВ-201 - Программа "Уход за больными" 2 курс
СД-101 - Программа "Сестринское дело" 1 курс
```

**Вариант 2: По кодам специальности**
```
34.02.01-1а - Сестринское дело, 1 курс, подгруппа А
34.02.01-1б - Сестринское дело, 1 курс, подгруппа Б
34.02.01-2а - Сестринское дело, 2 курс, подгруппа А
```

## 📅 Управление расписанием

### Добавление занятия

1. **Админ-панель → вкладка "Расписание"**
2. **Нажмите "Новое занятие"**
3. **Заполните:**
   - **Группа:** ПВ-201
   - **Предмет:** Анатомия человека
   - **Преподаватель:** И.О. Преподавателя
   - **День недели:** Выберите из списка
   - **Время начала:** 09:00
   - **Время конца:** 10:30
   - **Кабинет:** 401
4. **Нажмите "Сохранить"**

### Функции редактирования

- **🔍 Поиск** - введите часть названия группы, предмета, преподавателя или кабинета
- **📊 Сортировка:**
  - По дням - группировка по дням недели
  - По группам - группировка по названиям групп
  - По времени - сортировка по времени занятий
- **✏️ Редактирование** - нажмите иконку карандаша для изменения
- **📋 Дублирование** - нажмите иконку скрепки для быстрого создания похожего занятия
- **🗑️ Удаление** - нажмите иконку корзины
- **⬇️ Экспорт** - скачайте расписание группы в JSON

## 🔐 Аутентификация

### Вход в систему

**URL:** http://localhost:5000/auth

Введите email и пароль для входа.

### Личные кабинеты

После входа в систему каждый пользователь получает доступ к личному кабинету:

**👨‍🎓 Для студентов и учителей:**
- URL: http://localhost:5000/dashboard
- 📅 Просмотр расписания своей группы
- 📰 Актуальные новости
- 👤 Профиль с информацией о себе
- Удобный интерфейс с вкладками

**🔑 Для администраторов:**
- URL: http://localhost:5000/admin
- 👥 Управление пользователями
- 📚 Управление группами
- 📅 Редактирование расписания
- 📊 Статистика системы

### Технические детали

- Используется **JWT (JSON Web Token)** для аутентификации
- Токен хранится в `localStorage`
- Токен отправляется в заголовке `Authorization: Bearer <token>`
- Сессия хранится в браузере до выхода

## 🚀 Развертывание

### Production сборка

```bash
npm run build
npm start
```

Приложение будет доступно на http://localhost:5000

### Docker (опционально)

1. Создайте `Dockerfile`:

```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build
EXPOSE 5000
CMD ["npm", "start"]
```

2. Сборка и запуск:

```bash
docker build -t college-site .
docker run -p 5000:5000 college-site
```

## 🐛 Решение проблем

### Порт 5000 уже занят

```bash
# Linux/Mac
lsof -i :5000 | grep LISTEN | awk '{print $2}' | xargs kill -9

# Windows
netstat -ano | findstr :5000
taskkill /PID <PID> /F
```

### Module not found

```bash
rm -rf node_modules package-lock.json
npm install
```

### БД не работает

```bash
npm run db:push
```

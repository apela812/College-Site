# 🏥 Альметьевский Медицинский Колледж

Современный веб-сайт медицинского колледжа.

## 🚀 Быстрый старт

### Способ 1: Интерактивный лаунчер (Рекомендуется)

```bash
python run.py
```

Откроется красивое меню со всеми действиями.

### Способ 2: Через npm

```bash
npm install      # Установка зависимостей
npm run dev      # Запуск в режиме разработки
```

---

## ✨ Функции интерактивного меню

При запуске `python run.py`:

- ▶ **Запустить проект (dev)** - разработка на http://localhost:5173
- 🏗️ **Собрать проект (build)** - production версия
- 📦 **Запустить собранный проект** - запуск production
- 📥 **Переустановить зависимости** - очистка и переустановка
- ℹ️ **Информация о проекте** - данные о проекте
- 🔄 **Проверить требования** - проверка Node.js/npm
- ❌ **Выход** - выход

---

## 📋 Требования

- **Node.js** 16+ ([скачать](https://nodejs.org/))
- **npm** 7+ (идет с Node.js)
- **Python 3** (для `python run.py`)

---

## 📚 Команды

```bash
npm run dev      # Разработка
npm run build    # Сборка
npm start        # Запуск production
npm run check    # Проверка типов
npm run db:push  # Синхронизация БД
```

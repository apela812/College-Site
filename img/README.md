## 📸 Как добавить скриншоты

Скриншоты для галереи в README находятся в папке `img/`. 

Для правильного отображения скриншотов в README нужно сохранить следующие файлы в эту папку:

1. **home.png** - Главная страница
2. **about.png** - О колледже
3. **students.png** - Студентам
4. **news.png** - Новости
5. **schedule.png** - Расписание
6. **announcements.png** - Объявления
7. **contacts.png** - Контакты
8. **admin-panel.png** - Админ-панель (главная)
9. **stats.png** - Статистика системы
10. **schedule-manager.png** - Управление расписанием
11. **schedule-viewer.png** - Просмотр расписания
12. **create-group.png** - Создание новой группы
13. **users.png** - Управление пользователями

После добавления скриншотов они автоматически будут отображаться в README на GitHub.

**Рекомендации:**
- Размер: 1200x700px или больше
- Формат: PNG (без сжатия - для лучшего качества)
- Каждый скрин должен четко показывать интерфейс без приватной информации
